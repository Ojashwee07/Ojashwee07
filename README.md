## 🚀 Featured Projects

### 🛍️ [Shringar: Full-Stack E-Commerce Platform](https://github.com/Ojashwee07/Shringar)
A distributed SaaS platform with a React frontend and a Node.js/Express backend exposing 15+ REST APIs (auth, product, cart, order, admin). Features JWT authentication with role-based access control, salted password hashing, and Razorpay/Stripe payment integration with HMAC signature verification. Deployed on AWS EC2.

`React` `Node.js` `Express.js` `MongoDB` `JWT` `Razorpay/Stripe` `AWS EC2`

### ✈️ [AOCE: Airport Operations Coordination Engine](https://github.com/Ojashwee07)
A control-room style web app for coordinating airport operations, with an interactive React dashboard built with Tailwind, Recharts and Leaflet, backed by a FastAPI service. *(In progress)*

`React` `Vite` `Tailwind` `Recharts` `Leaflet` `FastAPI` `SQLAlchemy` `LangGraph`

### 🤖 [TriageAI: LLM-Integrated Decision Automation Engine](https://github.com/Ojashwee07/TriageAI)
A containerized decision engine that integrates the Qwen2.5-72B-Instruct LLM API into a rule-based Q-Learning system, with a FastAPI + Pydantic service layer for validated, structured outputs.

`Python` `FastAPI` `Pydantic` `Docker` `Qwen2.5-72B-Instruct`

### 💰 [ETMS: GenAI-Powered Expense Automation](https://github.com/Ojashwee07/ETMS)
An expense management system that uses the Google Gemini API to auto-extract structured data from unstructured text, plus a Splitwise-style greedy debt-simplification feature for group expense reconciliation. Built with a FastAPI + MongoDB backend.

`Python` `FastAPI` `MongoDB` `Google Gemini API`

### 🍽️ Restaurant Order Automation Bot (n8n Workflow)
An end-to-end conversational ordering system built on n8n. It uses an AI Agent node (Gemini) with session memory, Telegram webhook triggers, and real-time inventory sync via Google Sheets, and is containerized with Docker.

`n8n` `Google Gemini API` `Telegram API` `Docker` `Google Sheets`
